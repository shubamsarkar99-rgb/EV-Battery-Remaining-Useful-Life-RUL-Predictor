# EV Battery Remaining Useful Life (RUL) Prediction

This project simulates and predicts the **Remaining Useful Life (RUL)** of Electric Vehicle (EV) batteries using Machine Learning and a Streamlit dashboard.

---

### Dashboard Preview

![EV Battery Simulation Dashboard](./assets/photo.png)

---

### Project Structure

* **`app.py`**: Streamlit interface for live battery parameter inputs and predictions.
* **`model.pkl`**: Trained Gradient Boosting model exported from Google Colab.
* **`requirements.txt`**: Locked dependencies (`scikit-learn==1.6.1`).
* **`assets/photo.png`**: Project dashboard screenshot.
